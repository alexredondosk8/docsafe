¿Cómo cambiar la configuración?

Por seguridad, esta página es de solo lectura. Edita el archivo .env en la carpeta del proyecto y reinicia la aplicación:

LLM_BASE_URL=http://localhost:11434/v1
LLM_MODEL=nombre-del-modelo
LLM_API_KEY=
LLM_TIMEOUT=120

Con Ollama no hace falta clave. La clave API nunca se muestra en la aplicación ni se envía al navegador.
